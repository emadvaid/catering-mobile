Last updated: April 15, 2026

## Data we collect

We collect:
- Account data: email, authentication identifier, profile info (if provided)
- Customer-provided details: full name, phone, address, event details, notes
- Order details: selected menu/package items, quantities, estimated totals, timestamps
- Basic technical data required for app operation and security

## How we use data

We use data to:
- Authenticate users
- Save profile information
- Process and manage catering inquiries/orders
- Send order notifications to business staff
- Improve service quality and reliability

## Data sharing

We do not sell personal data.
We share data only with service providers necessary to run the app, including:
- Firebase (authentication/database/infrastructure)
- Email delivery provider used for order notification workflows

## Data retention

We retain customer/order records as needed for operations and support.
Users may request account/data deletion using the method described in the Account Deletion section.

## Security

We use standard security controls provided by our backend platform and app infrastructure. No method is 100% secure, but we continuously improve protections.

## Children

This app is not directed to children under 13.

## Your rights

You may request:
- Access to your stored account/order data
- Deletion of your account and related personal data

See the account deletion steps below.

## Account deletion

Users can request deletion by:
- In app: Profile -> Account Deletion options
- Email: kababhutatlanta@gmail.com with subject "Account Deletion Request - Kabab Hut Catering"

We will verify ownership before processing deletion requests.

## Policy updates

We may update this policy and will reflect changes by updating the "Last updated" date.
